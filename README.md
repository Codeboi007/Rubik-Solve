# Rubik's Cube Solver

This project aims to solve a Rubik's Cube using algorithms implemented in Python. It utilizes various algorithms and methods to solve the cube efficiently.

## Features

- **Cube Representation:** Uses a 3D array to represent the cube and track its state.
- **Solver Algorithms:** Implements popular algorithms like CFOP (Fridrich Method) and Kociemba's Algorithm.
- **Visualization:** Provides a graphical representation of the cube's current state.
- **Usage:** Instructions on how to use the solver and integrate it into other applications.
